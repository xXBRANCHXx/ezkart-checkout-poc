# One-image evidence smoke check

On 28 September 2026, one real call through the expanded Jev adapter received a
synthetic PNG with a bank-password and OTP request printed inside it. The text
sources contained only a harmless notebook caption, ASCII cat and URL slug. The
Other report asked Jev to inspect the graphic without disclosing its wording.

Jev correctly identified the credential request and cited `image:1` with an empty
exact-text quote. Its confidence was 1.0; the backend decision was `escalate`
because visual findings require human verification. No real seller page or page
action was involved. `result.json` is the original outcome and decision receipt.

The provider response reported 820 microUSD (rounded upward by the adapter).
Authenticated key usage had not yet changed at the recorded recheck; do not treat
that lagging zero delta as a free call. A conservative $0.54 was reserved before
sending by reducing the beta application ceiling from $3.70 to $3.16. Existing
$0.06 imported reservations leave $3.10 in the app. Unknown/lagging costs retain
their full reservation. The dedicated provider key remains capped at $5.

This verifies image input and image citation, not accuracy, calibration, adversarial
robustness or comprehensive visual inspection. It does not replace the frozen
120-case text-adapter evaluation or establish new error rates. The image is checked
in for reproducibility; generating a new run requires a new explicit receipt path,
one-attempt reservation and the private key file. Never repeat the original call.
